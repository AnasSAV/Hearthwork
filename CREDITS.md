# Credits

## LimeZu

All game art (characters, town, houses and interiors) is by **LimeZu**:
[Modern Interiors](https://limezu.itch.io/moderninteriors) and
[Modern Exteriors](https://limezu.itch.io/modernexteriors). These packs are paid and licensed:
they may be used and edited in this game with credit, but not redistributed or resold. The
repository only contains small atlases derived from them by `tools/art/`; get the packs from
LimeZu to regenerate or extend the art.

| File in `client/public/assets/`              | Source                                                                                                                                                                      | How it was derived                                                                                                 |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `characters/{body,eyes,outfit,hair,acc}.png` | Modern Interiors, `2_Characters/Character_Generator/*/16x16`                                                                                                                | `tools/art/build_characters.py`: idle, walk and sit rows of each part (16×32 frames), packed 5 parts per atlas row |
| `tilesets/town.png`                          | Modern Exteriors, `ME_Theme_Sorter_16x16/*_Singles_16x16` and `1_Terrains_and_Fences`                                                                                       | `tools/art/build_town.py`: every 16×16 tile the town map uses, deduplicated                                        |
| `sprites/houses.png` (+ `.json`)             | Modern Exteriors, Camping `Mobile_House_{Small,Medium,Big}_{1,2}`                                                                                                           | `tools/art/build_town.py`: house exteriors per style and level, drawn in each yard                                 |
| `sprites/town-anims.png` (+ `.json`)         | Modern Exteriors, `Animated_16x16/Animated_sheets_16x16` (flag, fish, garden fountain)                                                                                      | `tools/art/build_town.py`: animation strips stacked, frames named `<anim>:<i>`                                     |
| `sprites/town-map.png`                       | (rendered from the town map)                                                                                                                                                | `tools/art/build_town.py`: the whole town scaled down, for the world map                                           |
| `tilesets/furniture.png`                     | Modern Interiors, `Theme_Sorter_Singles` (living room, bedroom, library, music, art, kitchen), `Theme_Sorter/2_LivingRoom` (sofas); Modern Exteriors singles (garden items) | `tools/art/build_interiors.py`: one sprite per catalog item, packed                                                |
| `tilesets/room.png`                          | Modern Interiors, `Room_Builder_subfiles` (walls, floors, borders)                                                                                                          | `tools/art/build_interiors.py`: 3×2 wall and floor blocks per style, room border                                   |
| `tilesets/yard.png`                          | Modern Exteriors: terrain grass, `Sidewalk_1_25`, Additional Houses `Fence_1_*`, Camping `Sign_6`                                                                           | `tools/art/build_interiors.py`: yard ground, path, fence ring and the Town signpost                                |

## Maps

- `maps/town.tmx` (Tiled) and `maps/town.json` (Phaser and server) are generated by
  `tools/art/build_town.py` from the LimeZu pack. Edit the `.tmx` in
  [Tiled](https://www.mapeditor.org/) and re-export JSON with tilesets embedded.

## Audio

- The radio's default tracks and the ambient sounds are generated live in the browser with
  WebAudio (`client/src/audio/`). They are original to this project (CC0); no audio files are
  shipped. Any real tracks added to `client/public/radio/playlist.json` must be license-cleared,
  with the license recorded in their `license` field.
